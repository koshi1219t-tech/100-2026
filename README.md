# #100-2026

## 目的

この100日間で、AIに全て任せ切ることなく、AIを使用しながら自分で設計し、実装し、問題を発見し、修正し、改善できること

## 方針

- AIに全部任せて自分の技術力がつかないことが無いようにする
- 自分で基本的に全て理解し、説明できるようにする
- 失敗することは恥ではない
- 100日間で同じものを複数個作ることによって、技術力の向上・高速化・正確性の向上・作成物の質の向上・逆算的思考を身につけ検証すること

## 最終目標

- 100日後に自分一人でもAIをsupporterとして利用しながら、新しいシステムを設計から完成までまで持っていける状態を目指す。
- 100日後に自分一人で学習済みのシステムを設計から完成まで持っていける状態を目指す。
