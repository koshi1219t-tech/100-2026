# Day 1 Bemchmark

## 作るもの

個人タスク管理アプリ

## 目的

100日後との比較基準を作る

Day １では高度な機能を入れず、現在の自分の技術力でどこまで設計・実装・検証できるかを記録する。

## 必須機能

- タスクを追加できる
- タスク一覧を表示出来る
- 完了・未完了を切り替えれる
- タスクを削除できる
- アプリを終了してもデータが残る

## 使用技術

- python
- JSON

## 入れないもの

Day 1では以下を実装しない

- ログイン機能
- クラウド
- AI機能
- Docker
- CI/CD
-　複雑なデータベース
-　高度なUI

## 完成条件

必須機能が全て動作し、通常の操作といくつかの異常操作を確認できていること。
